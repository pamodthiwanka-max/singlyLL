# LibDataStructures-C

A lightweight and generic **data structures library written in C**.

The goal of this project is to implement common data structures from scratch while keeping the library **reusable, modular, memory-safe, and easy to understand**.

## Features

- Generic data structures using C
- Dynamic memory allocation
- Modular `.h` and `.c` files
- Function-pointer based operations
- Easy-to-use APIs
- Reusable and maintainable code
- Clean C programming practices
- Memory management and safety considerations

##  Data Structures

Currently implemented:

- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Stack
- Queue
- Binary Search Tree
- Heap
- Hash Table
- Graph

##  Project Goals

The long-term goal is to build a reusable C library containing fundamental data structures and algorithms.

The project focuses on:

1. Correct implementations
2. Memory safety
3. Time and space complexity
4. Generic data handling
5. Modular design
6. Testing
7. Clean C programming practices
8. Reusable APIs

##  Learning Objectives

This project helps strengthen understanding of:

- Pointers
- Structures
- Dynamic memory allocation
- Function pointers
- `void *`
- Header files
- Header guards
- Modular programming
- Data structures
- Algorithms
- Memory management
